ПОДТВЕРЖДЕНИЕ ПОЧТЫ EXXPRESS

В проекте уже реализована регистрация и вход через Supabase Auth.
При регистрации Supabase отправляет письмо со ссылкой подтверждения (не шестизначный код).

Перед тестом:
1. В Supabase открой Authentication -> URL Configuration.
2. Site URL можно оставить http://localhost:8000 для локального теста.
3. В Redirect URLs добавь обе строки:
   http://localhost:8000/**
   http://127.0.0.1:8000/**
4. В Authentication -> Sign In / Providers -> Email включи Confirm email.
5. Убедись, что SQL из supabase-schema.sql выполнен без ошибок.
6. Запусти сервер в папке проекта командой npm start.
7. Открывай сайт по http://127.0.0.1:8000 или http://localhost:8000.
8. Нажми «Войти» -> «Регистрация», укажи свою почту, пароль от 8 символов и имя.
9. Открой письмо от Supabase и нажми ссылку подтверждения. Затем вернись на сайт и войди.

Важно:
- В письме будет ссылка, а не код.
- Не отправляй никому пароль, Secret key, service_role или пароль базы данных.
- Publishable key в supabase-config.js предназначен для браузера; безопасность данных обеспечивается RLS.
- Пока сайт работает только локально на этом ПК. Для доступа другим людям потребуется бесплатный/платный хостинг и корректные URL.
