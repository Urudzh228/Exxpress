EXXPRESS 1.4 — ПОДКЛЮЧЕНИЕ К SUPABASE

Что подключено в этой сборке:
- регистрация и вход через Supabase Auth;
- подтверждение адреса электронной почты письмом Supabase Auth;
- загрузка общих объявлений из таблицы listings;
- создание, редактирование и удаление собственных облачных объявлений;
- создание переписок по облачным объявлениям и хранение сообщений в Supabase;
- RLS-политики для ограничения доступа к профилям, объявлениям и сообщениям.

ШАГ 1. НАСТРОИТЬ КЛЮЧИ
1. Открой supabase-config.js в Блокноте.
2. В строке anonKey замени PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE на свой Publishable key целиком, одной строкой.
3. Сохрани файл. URL проекта уже указан.
4. Не вставляй Secret key, service_role или пароль базы данных. Они не нужны фронтенду.

ШАГ 2. СОЗДАТЬ ТАБЛИЦЫ И ПРАВИЛА БЕЗОПАСНОСТИ
1. В Supabase открой SQL Editor.
2. Нажми New query.
3. Открой файл supabase-schema.sql, скопируй его целиком и вставь в редактор.
4. Нажми Run. Должно выполниться без ошибок.

ШАГ 3. НАСТРОИТЬ ПОДТВЕРЖДЕНИЕ ПОЧТЫ
1. В Supabase открой Authentication → URL Configuration.
2. Для локальной проверки добавь http://localhost:8000 в Redirect URLs.
3. В Authentication → Providers → Email оставь включённым подтверждение email.
4. Supabase отправляет подтверждение через свою почтовую систему. Для собственного SMTP можно отдельно настроить SMTP в Authentication → SMTP Settings; не публикуй пароль SMTP.

ШАГ 4. ЗАПУСК НА ПК
1. Распакуй архив.
2. Открой папку Exxpres.
3. В адресной строке Проводника напиши cmd и нажми Enter.
4. Выполни: python -m http.server 8000
5. Открой http://localhost:8000

ПРИМЕЧАНИЯ
- Это первая облачная версия. Регистрация, подтверждение email, объявления и чат работают через Supabase после выполнения SQL и настройки ключа.
- Заказы, корзина, избранное и отзывы пока остаются локальными и не синхронизируются между устройствами.
- Демонстрационные товары в каталоге остаются примерами. В облако записываются объявления, которые пользователь публикует после входа.
- Чат хранит сообщения в базе, но автоматическое realtime-обновление пока не включено: чтобы увидеть новые сообщения, открой переписку заново.
- Настоящие платежи, доставка, возвраты и модерация не реализованы. Не размещай паспортные данные и не используй сайт для реальных денежных сделок.
- Бесплатные лимиты Supabase могут меняться; проверь актуальные условия в панели проекта.
